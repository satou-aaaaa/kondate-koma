# 献立こま

1日の献立に足りない料理を見つけて1品足し、「食事バランスガイド」のこまを回す1日5問のゲーム。時間制限なし。

- 遊ぶ: https://satou-aaaaa.github.io/kondate-koma/
- 料理は主食・副菜・主菜・牛乳・乳製品・果物の5つのなかまに分かれます。1つだけ、1日の目安より少ないなかまがあります。4品から1品を足して、全部そろえるとこまが回ります。
- 今日の5問（やさしい2・ふつう2・むずかしい1）はだれでも同じで1日1回。上級（むずかしい3問・ヒントなし）、練習（何度でも）、とことん（まちがえても続く・好きなだけ）、足した料理が集まる「料理帳」があります。
- やさしいは、こまの数が見えます。ふつうは、料理になかまの印（主食1 など）が出ます。むずかしいは、何も見えません。
- ヒントは「足りないなかまを言い、こまの数を見せる」→「選び肢を2つにしぼる」の2段です。
- 見やすさの設定（読みやすい文字・色の見分け・動きを減らす・読み上げ）と、機種を変えるときの「引き継ぎ」があります。

## 出どころ

料理と「つ（SV）」、1日の目安（基本形 2200±200kcal：主食5〜7・副菜5〜6・主菜3〜5・牛乳・乳製品2・果物2）は、厚生労働省・農林水産省「食事バランスガイド」です。

- 農林水産省「食事バランスガイド」の適量と料理区分： <https://www.maff.go.jp/j/syokuiku/kenzensyokuseikatsu/about_b_guide.html>（料理例とチェックチャートを 2026-11-07 に確認）
- 厚生労働省「食事バランスガイド」について： <https://www.mhlw.go.jp/bunya/kenkou/eiyou-syokuji.html>

合う量は、年齢・体の大きさ・活動の量で変わります。このゲームは、食事のなかまと量の考え方に親しむためのもので、病気の食事の指導ではありません。

## 記録と通信

記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を読み込むとき、まだ端末に保存が無ければ Google に IP アドレスが届きます。「X」「LINE」「ほかのアプリで送る」を押したときだけ、結果の文が選んだ先に渡ります（献立と答えは入りません）。
